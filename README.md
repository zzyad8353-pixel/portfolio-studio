# PlayStation R2 Hub

منصة حجوزات صالة ألعاب PlayStation R2، وتتكون من واجهة عميل ولوحة تحكم إدارية في نفس المشروع مع قاعدة بيانات وواجهات API مشتركة.

## مسارات الموقع

- `/` واجهة العميل: الصفحة الرئيسية، الأجهزة المتاحة، نموذج الحجز، حساب السعر الفوري، وبيانات الصالة.
- `/admin` لوحة الإدارة: الإحصائيات، الأجهزة والغرف، الحجوزات، إعدادات الهوية والمحتوى، ولون النيون.
- `/admin` لا تعرض محتواها إلا بعد كلمة السر المحلية `123456`، ولا تعتمد على Manus OAuth.
- العميل ينشئ حسابًا برقم الهاتف وكلمة السر قبل تأكيد أي حجز، ثم تظهر له صفحة «حجوزاتي» الخاصة به فقط.

## الربط الديناميكي

كل البيانات المهمة تمر من خلال قاعدة البيانات وواجهات tRPC المشتركة. تعديل اسم البراند أو النصوص أو الهاتف أو العنوان أو لون النيون من لوحة الإدارة ينعكس على واجهة العميل. إضافة جهاز أو تعديل حالته وأسعاره يغيّر قائمة الحجز والحاسبة مباشرة. إنشاء أو تحديث الحجز ينعكس في لوحة الإدارة والإحصائيات.

يوجد fallback تجريبي داخل الخادم حتى تعمل المعاينة قبل إدخال بيانات حقيقية، بينما تستخدم بيئة التشغيل قاعدة البيانات عند توفر `DATABASE_URL`.

## الملفات الرئيسية

| الملف | الوظيفة |
|---|---|
| `client/src/pages/Home.tsx` | واجهة الزائر والحجز الفوري |
| `client/src/pages/Admin.tsx` | لوحة التحكم الإدارية |
| `client/src/index.css` | الثيم الداكن والنيون والتجاوب |
| `server/routers.ts` | إجراءات الإعدادات والأجهزة والحجوزات والإحصائيات |
| `server/db.ts` | اتصال Drizzle بقاعدة البيانات |
| `drizzle/schema.ts` | جداول المستخدمين والإعدادات والأجهزة والحجوزات |
| `drizzle/0001_strange_wonder_man.sql` | ترحيل الجداول الجديدة |
| `server/playstation-r2.test.ts` | اختبارات الربط والتسعير والتخصيص |

## ملاحظة قبل الإطلاق العام

تم تفعيل حماية لوحة الإدارة بجلسة محلية مستقلة عن Manus. حسابات العملاء منفصلة، وكلمات السر لا تُخزّن كنص صريح؛ تُخزّن كـ hash مع salt. يجب تغيير `ADMIN_PASSWORD` ووضع `JWT_SECRET` قوي في بيئة الإنتاج.
